## 🆕 Tính năng mới

### 1. Configuration Management
- **File:** `configs/config.py`
- **Mô tả:** Centralized configuration với Python dataclass
- **Lợi ích:** Dễ dàng thay đổi hyperparameters mà không cần sửa code

```python
config = Config(
    model_name="vinai/phobert-base",
    num_labels=7,
    batch_size=16,
    learning_rate=2e-5,
    enable_emoji_embedding=True
)
```

### 2. Modular Data Pipeline
- **Module:** `src/data/dataset.py`
- **Classes:**
  - `EmotionDataset`: Custom PyTorch Dataset
  - `load_uit_vsmec_dataset()`: Load dataset from HuggingFace
  - `create_dataloaders()`: Create train/val/test loaders

### 3. Model Architecture
- **Module:** `src/models/phobert_emotion.py`
- **Class:** `PhoBERTEmotionClassifier`
- **Features:**
  - Clean separation of model architecture
  - Easy to extend with different heads
  - Support for custom dropout and hidden sizes

### 4. Emoji Embedding Utilities
- **Module:** `src/models/emoji_embeddings.py`
- **Functions:**
  - `apply_emoji_embeddings()`: Transfer embeddings từ từ tiếng Việt
  - `load_emoji_mapping_from_file()`: Load custom mappings
- **Default mapping:** 20+ emojis được hỗ trợ

### 5. Multiple Loss Functions
- **Module:** `src/losses/`
- **Implementations:**
  - `FocalLoss`: Xử lý class imbalance
  - `WeightedCrossEntropyLoss`: Class-weighted CE
  - `compute_class_weights()`: Tự động tính weights

### 6. Comprehensive Metrics
- **Module:** `src/utils/metrics.py`
- **Functions:**
  - `compute_metrics()`: Accuracy, Precision, Recall, F1
  - `compute_confusion_matrix()`: Confusion matrix
  - `plot_confusion_matrix()`: Visualization
  - `print_classification_report()`: Detailed report

### 7. Advanced Logging
- **Module:** `src/utils/logger.py`
- **Features:**
  - `setup_logger()`: Console + file logging
  - `MetricsTracker`: Track training history
  - `save_metrics_to_file()`: JSON export

### 8. Training Script
- **File:** `scripts/train.py`
- **Features:**
  - ✅ Complete training loop với progress bars
  - ✅ Early stopping
  - ✅ Model checkpointing (best + final)
  - ✅ Learning rate scheduling
  - ✅ Gradient clipping
  - ✅ Metrics tracking and logging
  - ✅ Command-line arguments support

**Usage:**
```bash
python scripts/train.py --batch_size 32 --num_epochs 20 --learning_rate 3e-5
```

### 9. Evaluation Script
- **File:** `scripts/evaluate.py`
- **Features:**
  - ✅ Load và evaluate model checkpoints
  - ✅ Support nhiều splits (train/val/test)
  - ✅ Confusion matrix plotting
  - ✅ Classification report
  - ✅ Save predictions to file

**Usage:**
```bash
python scripts/evaluate.py \
    --checkpoint checkpoints/best_model.pt \
    --split test \
    --plot_cm \
    --save_predictions
```

## 🐛 Known Issues & Limitations

1. **VnCoreNLP Integration**: Chưa tích hợp đầy đủ word segmentation
   - **Workaround**: Có thể thêm sau nếu cần
   - **Status**: Optional feature

2. **Distributed Training**: Chưa hỗ trợ multi-GPU training
   - **Workaround**: Sử dụng `accelerate` library (đã có trong requirements)
   - **Plan**: Sẽ thêm trong phiên bản tương lai

3. **Hyperparameter Tuning**: Chưa có auto-tuning
   - **Workaround**: Điều chỉnh manual qua config
   - **Plan**: Có thể tích hợp Optuna hoặc Ray Tune
